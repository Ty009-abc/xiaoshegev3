# SMOKE_MATRIX.md — 固定Smoke检查清单

> 每次 Preview 生产前必须执行的快速验证矩阵。
> 不能只测试当前改动 — 必须覆盖三类海报和关键功能。

## 页面与功能

| # | 检查项 | 方法 |
|---|--------|------|
| 1 | 首页加载正常 | 扫码进入首页 |
| 2 | 问卷提交成功 | 完成一次完整问卷 |
| 3 | 报告生成成功 | 问卷完成后跳转报告页 |
| 4 | 报告详情展示 | 查看五张卡：判决/矛盾/潜力/决策/行动 |
| 5 | 翻身报告海报 | 点击保存海报 → 相册中查看 |
| 6 | AI聊天 | 发送消息 → 收到回复 |
| 7 | 认知暴击海报 | 查看认知暴击 → 保存海报 |
| 8 | 世界规则详情 | 点击世界规则 → 查看详情 |
| 9 | 世界规则海报 | 保存世界规则海报 → 相册查看 |
| 10 | 历史记录 | 查看历史报告列表 |
| 11 | 收藏功能 | 收藏/取消收藏一个项目 |
| 12 | 会员入口 | 点击会员 → 显示会员状态 |
| 13 | 支付入口 | 点击支付 → 显示支付页 |
| 14 | 页面返回与Tab切换 | 多点切换页面无崩溃 |

## 三类海报验证（每次必查）

| 海报类型 | 关键检查 |
|---------|---------|
| 翻身报告海报 | verdict非空、decision非空、contradiction非FALLBACK、no undefined/null |
| 世界规则海报 | title/worldRule/underlyingLogic无重复、reverseLogic不空 |
| 认知暴击海报 | 文字可读、无截断、背景正常 |

## 禁止事项

- 只测试当前Bug → BLOCKED
- 跳过海报验证 → BLOCKED
- 用旧报告冒充新报告 → BLOCKED
- 出现 null/undefined/残句 → BLOCKED
